### 1.1.2 给变量注明类型
参考代码：typing_error.py

```python
from typing import List


def remove_invalid(items: List[int]):
    print(items)
    print(type(items))
    pass


remove_invalid(["piglei", "raymond"])
remove_invalid('test')
```

输出：
```
['piglei', 'raymond']
<class 'list'>
test
<class 'str'>
```



### 1.1.3 变量命名原则
1. 遵循PEP8原则
   - 普通变量：蛇形命名，max_value
   - 常量：全大写，MAX_VALUE
   - 仅内部使用：下划线前缀，_local_var
   - 与关键字冲突：下划线后缀，class_
2. 描述性要强
3. 要尽量短
4. 要匹配类型
   - 匹配布尔类型的变量名
   - 匹配int/float类型的变量名
5. 超短命名
