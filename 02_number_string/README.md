## 2.1 基础知识
###  2.1.1 数值类型
python的三种内置数值类型：
- int 整型
- float 浮点型
- complex 复数类型

数字特别长的话，可以用_分隔符使其易读。


如果需要精确的浮点数，请使用decimal.Decimal。必须使用字符串来表示数字。
```python

a = 0.1
b = 0.2
print(f"{a} + {b} = ", a + b)
'''
0.1 + 0.2 =  0.30000000000000004
'''

from decimal import Decimal
a = Decimal('0.1')
b = Decimal('0.2')
print(f"{a} + {b} = ", a + b)
'''
0.1 + 0.2 =  0.3
'''
```

###  2.1.4 不常用但是特别好用的字符串方法
str.isdigit()函数判断是否只包含数字

str.partition(sep):按照分隔符sep切分字符串，返回(part_before, sep, part_after)

str.translate(table):按规则一次性替换多个字符。
