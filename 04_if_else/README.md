# 第4章 条件分支控制流
## 4.1 基础知识
### 4.1.1 分支惯用写法
不要显式地和布尔值作比较
1. 省略零值判断
```python
bool(0)
Out[6]: False
bool([])
Out[7]: False
bool('')
Out[8]: False
```
- 布尔值为假：None,0,False,[],(),{},set(),frozenset()
- 布尔值为真：非0的数值，True, 非空的序列、元组、字典，用户定义的类和实例


2. 把否定逻辑移入表达式内
3. 尽可能让三元表达式保持简单


### 4.1.2 修改对象的布尔值
同时定义了__len__()和__bool__()，解释器会优先使用__bool__()。

### 4.1.3 与None比较时改用is运算符
类型的__eq__魔法方法，会在对象比较符号==时执行。

- （1）==对比两个对象的值是否相等，行为可被__eq__方法重载。
- （2）is判断两个对象是否是内存里的同一个东西，无法被重载。

- any(iterable): 只要iterable中任何一个成员的布尔值为真就返回True
