# 第7章 函数
## 7.1 基础知识
### 7.1.1 函数参数的常用技巧
1. 别将可变类型作为参数默认值。使用None来替代可变类型默认值。
2. 定义特殊对象来区分是滞提供了默认参数。
3. 定义仅限关键字参数
- 仅限关键字参数（keyword-only argument）
- 仅限位置参数（positional-only argument）

### 7.1.2 函数返回的常见模式
1. 尽量只返回一种类型
2. 谨慎返回None
   - 操作类函数的默认返回值
   - 意料之中的缺失值
   - 在执行失败时代表“错误”
3. 早返回，多返回

### 7.1.3 常用函数模块：functools
1. functools.partial() :返回一个新的可调用对象（callable object）
2. functools.lru_cache()：给函数加上缓存。

6. 总结
- 全局变量：增加模块级的全局状态，封装性和可维性最差
- 函数闭包：适合用来实现变量较少，较简单的有状态函数
- 创建类来封装状态：比闭包更易读，更容易维护。学习成本较高。
