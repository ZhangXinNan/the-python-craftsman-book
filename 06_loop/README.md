# 第6章 循环与可迭代对象
## 6.1 基础知识
### 6.1.1 迭代器与可迭代对象
1. iter()和next()内置函数
- iter() 尝试返回一个迭代器对象。 
- next() 返回下一次迭代结果。

2. 自定义迭代器
- __iter__()：迭代器对象总是返回自身。
- __next__()：通过return来返回结果。

3. 区分迭代器和可迭代对象
* 迭代器是可迭代对象的一种。
* **可迭代对象使用iter()会返回迭代器，迭代器则会返回自身**。
* 每个迭代器的被迭代过程是一次性的，可迭代对象不一定。
* 可迭代对象只需要实现__iter__()方法，而迭代器需要实现__iter__()和__next__()方法。
* 没有定义__iter__()，但是定义了__getitem__()，也认为它是可迭代的。

4. 生成器是迭代器
生成器是一种“懒惰的”可迭代对象，可以节约内存，提升执行效率。
