# 第5章 异常与错误处理
## 5.1 基础知识
### 5.1.1 优先使用异常捕捉
- LBYL(look before you leap)
  - 每次调用都先进行额外的isinstance和isdigit判断。
- EAFP(easier to ask for forgiveness than permission)
  - 每次调用直接执行转换，返回结果。


### 5.1.2 try语句常用知识
```python
def safe_int(value):
    try:
        return int(value)
    except TypeError:
        print("")
    except ValueError:
        print("")
    finally:
        print("")
```

1. 把更精确的except语句放在前面。
2. 使用else分支。仅当try语句块里没抛出任何异常时，才执行else分支下的内容。
3. 使用空raise语句。

### 5.1.4 使用上下文管理器
要创建一个上下文管理器，只要实现__enter__和__exit__两个魔法方法即可。

1. 用于替代finally语句清理资源。
2. 用于忽略异常。
3. 使用contextmanager装饰器。@contextmanager位于内置contextlib下，它可以把任何一个生成器函数直接转换为一个上下文管理器。
