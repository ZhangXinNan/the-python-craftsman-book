### 3.1.2 理解列表的可变性
- 可变(mutable)：列表、字典、集合
- 不可变（immutable)：整数、浮点数、字符串、字节串、元组
```python
a = 123
id(a)
# Out[3]: 140717056774760
a = 456
id(a)
# Out[5]: 2428963498448
```

- 值传递(pass-by-value)
- 引用传递（pass-by-reference）
- 传递“变量所指对象的引用”（pass-by-object-reference）
  - 是否改变，只取决于所有指向的对象本身是否可变

### 3.1.5 字典常用操作
1. 遍历字典
- 遍历字典对象，得到所有的key
- items()，可得到所有的key和value
2. 访问不存在的字典键
- 如果只是提供默认值的读取操作，可以用dict.get(key, default)
3. 使用setdefault取值并修改
dict.setdefault(key, default)
- 当key不存在时，把default值写入字典的key位置
- 当key存在时，直接返回它在字典中的对应值
4. 使用pop方法删除不存在的键
dict.pop(key, default)
只单纯的想去掉某个键，并不关心存在与否、是否删除成功。
5. 字典推导式

### 3.1.6 认识字典的有序性与无序性
python3.6之后，字典的key存储变有序了。
如果用旧版python，可使用collections模块的OrderedDict来保证字典有序。
两个内容完全相同而顺序不同的字典对象，3.6后的dict返回True，OrderedDict返回False。



### 3.1.7 集合常用操作
1. 不可变的集合frozenset
2. 集合运算
   - 交集：&、intersection
   - 并集：|、union
   - 差集：-、difference
3. 集合只能存放可哈希对象（hashable）

### 3.1.8 了解对象的可哈希性
内置函数hash(obj)，计算哈希值。

1. 所有不可变内置类型，都是可哈希的，例如：str/int/tuple/frozenset
2. 所有的可变内置类型，都是不可哈希的，例如：dict/list
3. 对于不可变容器类型（tuple、frozenset），仅当它的所有成员都不可变时，它本身才是可哈希的。
4. 用户自定义类型，默认是可哈希的。
